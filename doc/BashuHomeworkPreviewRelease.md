# 巴蜀版 ClassIsland 2.2.17

改进作业悬浮胶囊的调节操作与桌面显示。

- 调节宽度和内容缩放时，窗口及滑块面板保持原位；数值实时显示，关闭调节面板后统一应用并保存，避免滑块跟着窗口移动。
- 收起与展开状态均新增图钉按钮：竖直表示置顶，倾斜表示取消置顶，不使用变色表达状态。重启后记住选择。
- 作业悬浮窗不再单独占用任务栏；仍可从原有托盘菜单打开。
- 保留独立宽度设置、触屏与触笔拖动、位置记忆、班级作业同步、收起轮播，以及通知朗读修复。

提供 Windows x64、ARM64 安装包和便携包，附 SHA-256 校验文件。现有班级配对保留，便携包请完整解压后运行。

验证涵盖实际 Avalonia 窗口渲染、连续调节时窗口及面板坐标稳定、面板关闭应用、图钉切换与恢复、窗口关闭时保存、鼠标/触屏/触笔拖动、通知语音与作业同步回归，以及双架构编译和打包检查。自动输入检查不替代课堂一体机的物理触控验收。
