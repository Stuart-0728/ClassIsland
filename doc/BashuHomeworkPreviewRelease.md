# 巴蜀版 ClassIsland 2.2.20

作业悬浮窗统一显示「学科 · 作业内容」，长内容自动滚动，方便查看完整要求。

- 学科和分隔符固定在左侧，只滚动作业内容；收起胶囊与展开卡片保持一致。
- 短内容保持静止；超宽内容先停留片刻，再平滑横向滚动，鼠标悬停可暂停。
- 内容完整显示并停留后，才轮换下一项作业，避免被提前截断。
- 右侧收交状态与操作按钮保持固定，下方保留截止时间、收交状态及待补交名单。
- 旧作业未填写内容时回退显示标题，保留图钉置顶、位置记忆、独立宽度调节与触屏拖动。

提供 Windows x64、ARM64 安装包和便携包，附 SHA-256 校验文件。现有班级配对保留，便携包请完整解压后运行。

验证涵盖实际 Avalonia 窗口渲染、窄宽度布局、内容滚动和暂停、固定学科与状态、作业轮换、名单显示、图钉与拖动、缩放与位置恢复。发布流程另执行双架构编译、架构校验和安装包检查；自动化检查不替代课堂一体机的物理触控验收。
