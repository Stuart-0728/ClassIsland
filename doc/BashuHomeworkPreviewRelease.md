# 巴蜀版 ClassIsland 2.2.15

改进作业悬浮胶囊的显示、触屏拖动与位置记忆。

- 胶囊默认宽度增至 520，可在原有调节按钮中单独设置 320–960 的宽度；内容缩放不再带着胶囊变窄。
- 支持鼠标、触屏与触笔拖动。操作按钮仍正常点击，拖动被打断或关闭时也能保存位置。
- 自动记住位置、宽度、缩放和所在显示器；重启后恢复。调节缩放及展开、收起时保留定位，不再跳回右上角。
- 更换显示器、分辨率或缩放比例后，会将窗口限制在可见工作区内，避免悬浮窗移出屏幕。
- 保留收起轮播、平滑滚动、班级作业同步，以及 2.2.14 的通知朗读误停修复。

提供 Windows x64、ARM64 安装包和便携包，附 SHA-256 校验文件。现有班级配对保留，便携包请完整解压后运行。

验证包括实际 Avalonia 窗口渲染、连续缩放、按钮操作、鼠标/触屏/触笔输入、位置写盘与重新打开恢复、显示器移除回退，以及通知语音、作业同步和双架构编译检查。自动触屏输入检查不替代课堂一体机的物理触控验收。
