# 巴蜀版 ClassIsland 2.2.23

完善客户端手动同步与连接状态反馈，配合已上线的平台 2.3.27 修复重复回源导致的假性限流。

- “立即同步”同时刷新课表、通知和作业，等待当前请求完成并遵守服务器重试间隔，避免重复点击制造新一轮限流。
- 连接窗口分别显示课表/通知、作业的实时状态与成功同步时间，不再停留在上一次手动检查的旧提示；同步期间显示进度动画。
- 手动同步会重新读取完整作业数据，并可以重新打开已关闭的作业窗；自动同步仍尊重手动关闭。
- 修复界面更新失败后，相同版本作业数据无法重试恢复的问题。
- 初次尚未收到数据时显示“等待同步”，与服务器确认的“暂无作业”明确区分。
- 保留断网时最后一次名单、学科固定和作业内容滚动、图钉、触屏拖动及位置记忆。

平台 2.3.27 已上线：同一设备短间隔内的重复回源复用有效结果，不重复查询数据库，避免“第一次成功、第二次 429”覆盖同步数据。服务端仍对每次请求进行设备鉴权，并保留更新频率与缓存内存限制。

提供 Windows x64、ARM64 安装包及便携包。请覆盖安装到原目录保留班级配对。自动检查覆盖请求限流和取消、完整作业刷新、窗口手动恢复、显示异常后的同数据重试及完整 Windows 编译；课堂一体机的网络和触控体验仍需现场确认。
