# 巴蜀版 ClassIsland 2.2.21

修复省流策略下频繁限流、作业看板因临时断网关闭的问题。

- 空闲通知轮询约每 5 秒一次，作业同步约每 15 秒一次；按服务器建议间隔及 Retry-After 等待，连续失败时逐步延长重试间隔。
- 作业未变化时使用条件请求，避免反复传输相同名单；恢复联网后继续自动同步。
- 临时断网、限流或服务器异常时，作业看板保留最后同步的内容，显示「离线 · 上次同步时间」。手动关闭后，相同数据不会反复打开窗口。
- 解绑、配对失效或切换班级时清理旧班级内容及媒体连接。
- 启动、换日、切换课表配置和手动刷新时主动请求完整课表，兼容服务器小时级课表省流策略。
- 保留学科固定、仅作业内容滚动，以及图钉、位置记忆和触屏拖动。

完整课表主动刷新需要平台 2.3.26 或更高版本。旧平台仍可正常同步，部分省流响应头可由新平台补充。

提供 Windows x64、ARM64 安装包和便携包。自动化验证覆盖 HTTP 限流、重试、304 缓存、断网保留与恢复、权限边界，以及实际 Avalonia 窗口渲染；课堂一体机的实际网络和触控体验仍需现场验证。
