# 巴蜀版 ClassIsland 2.2.18

将作业标题移到悬浮窗上方，与学科以「 · 」分隔，方便一眼确认当前作业。

- 收起胶囊上方显示「学科 · 作业标题」，例如「物理 · 蜀光凝固」。
- 下方滚动内容只显示作业要求、截止时间、收交状态及名单，去掉重复的学科和标题。
- 展开后的作业卡片也使用相同标题格式。
- 长标题自动省略，悬停可查看完整标题；状态和操作按钮始终保留空间。
- 保留图钉置顶、位置记忆、独立宽度调节、触屏拖动，以及既有作业同步和语音通知修复。

提供 Windows x64、ARM64 安装包和便携包，附 SHA-256 校验文件。现有班级配对保留，便携包请完整解压后运行。

验证包括实际 Avalonia 窗口渲染、长标题在 520/320 宽度下的布局、标题及正文轮播、名单隐私、图钉与拖动、缩放与位置恢复，以及 Windows 双架构编译和打包检查。自动化检查不替代课堂一体机的物理触控验收。
