# 巴蜀版 ClassIsland 2.2.13-preview.2

本次整合最新作业悬浮窗及通知语音修复。

- 悬浮窗默认紧凑显示，以学科为标题；支持收起后逐科轮播、长文本平滑滚动、悬停暂停及切换动画。
- 保留拖动、大小调整和展开查看未交名单；复用平台班级配对自动同步作业与补交结果。
- 在线语音适配 edge-tts 7.3.1 v2 校验，修复旧版请求返回 403 后无法播报的问题。
- 遇到在线语音超时、拒绝或播放失败时，自动尝试系统语音；确认关闭时停止朗读。
- 改善语音请求取消、连接释放和文本转义，保留原有在线音色与音量设置。

提供 Windows x64、ARM64 安装包及便携包，附 SHA-256 校验文件。请下载匹配设备架构的版本；安装版使用独立测试目录，便携版需完整解压后运行。

验证包含协议和语音失败回归、完整 Windows 编译、双架构文件检查及 x64 Windows 启动与关闭检查。ARM64 实机扬声器播报仍需在课堂设备验收。
