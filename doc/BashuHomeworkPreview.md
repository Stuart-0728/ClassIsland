# 巴蜀版 ClassIsland 作业悬浮窗测试版

版本：2.2.10-preview.1。仅演示数据，不读取真实学生，不联网同步作业，不上传清查状态。

## 打开方式

- 安装版：运行对应 Windows x64 或 ARM64 的 Setup.exe，桌面快捷方式直接进入独立演示。
- 便携版：完整解压后双击 Start-Homework-Preview.cmd。
- 已启动本测试版完整 ClassIsland：主岛右键菜单选择“作业悬浮窗（演示测试版）”。

独立演示入口在平台服务启动前执行，不读取正式版班级配对，不启动对讲、自动更新或开机自启动。安装目录与卸载标识独立于正式版。请勿将便携包覆盖正式版目录。

## 可以体验

拖动标题区域移动窗口；收起/展开；调整字号；隐藏/显示模拟姓名；拖动窗口边缘调整大小；从底部下拉菜单切换演示状态，或点击“下一步”。

1. 布置作业：展示两科作业内容与截止说明，清查前不展示未交名单。
2. 清查完成：物理待补交3人、数学2人；每科48人中2人请假/免交，应交46人。
3. 学生补交：示例同学甲补交物理，自动从该名单移除；待补交合计4人次。
4. 全部交齐：两科全部完成，姓名列表清空。下一步重新开始演示。

“人次”按作业计算，不能当成去重学生人数。所有姓名均为“示例同学”占位。

本轮不包含真实作业同步、清查提交、自动按上下课展开、订正追踪；待界面确认后再接入网页/小程序和设备权限接口。

## 验证边界

包含状态回归测试、完整客户端编译、双架构原生文件校验；x64 在 Windows 构建机检查原生窗口启动与关闭。ARM64 仍需对应真机验收；安装包未代码签名。
