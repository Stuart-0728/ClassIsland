# 巴蜀版 ClassIsland 作业同步测试版

版本：2.2.13-preview.1。

## 使用方式

安装版通过桌面快捷方式进入完整 ClassIsland；免安装版完整解压后打开 Start-Platform-Homework.cmd。
在客户端的“两江巴蜀平台”设置中复用已有班级配对，或输入平台“大屏通知”页面生成的配对码。
平台需先部署支持 `/api/display-client/homework` 的版本（包含迁移 058）。未升级平台时不会显示真实作业。

新版每 5 秒同步当前配对班级的已布置、未归档作业；平台设备列表显示“作业悬浮窗已连接”。
新作业显示“待清查”；老师保存清点结果后开始显示未交名单，补交后自动移除；全班已交且无需修改时点击平台的喇叭“发布清查结果”。
归档或删除后自动移除，断线时关闭旧名单，重新连接后获取最新数据。旧历史作业先显示待清查，需要重新确认。

可拖动、收起。关闭窗口后相同数据不会反复弹出；新数据到达时重新打开，也可从主岛右键菜单“班级作业（平台同步）”重新打开。

纯演示入口仍保留：Start-Homework-Preview.cmd，使用示例数据，不联网。

测试版使用独立安装目录；请勿覆盖正式版目录，也不要让两套完整客户端同时运行。完整客户端保留原有课表、对讲和开机启动行为。

## 验证与许可

包含服务端接口隔离联调、客户端状态回归、Windows 完整编译及双架构文件检查。
安装包未代码签名，课堂设备上的实际联机效果仍需验收。
源码基于 Stuart-0728/ClassIsland，遵循 GPL-3.0 许可证。

收起后逐科轮播作业内容、截止时间与收交状态；长文字平滑滚动，鼠标悬停暂停。悬浮窗只展示班级、作业内容、收交状态与未交名单，不显示设置或演示控制。

## 语音播报修复

在线 EdgeTTS 服务拒绝请求、超时或音频播放失败时，自动尝试 Windows 系统语音。请保留系统中文语音包和可用的扬声器输出；确认关闭通知后会同步停止备用朗读。此修复需更新大屏客户端，平台服务器无需重启。
